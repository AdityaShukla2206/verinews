Project Abstract

Digital communication platforms in India suffer from an unprecedented rise in fake news and automated financial phishing scams. This project presents VeriNews AI v3.1, an integrated pipeline combining a TF-IDF (word + character n-gram) machine-learning classifier with rule-based linguistic and URL threat scanners, curated fact-registry retrieval and optional Google Fact Check lookup. Transformer fine-tuning (XLM-R / MuRIL) is future work.

Research Objectives

  • Process multi-lingual text inputs including English, Hindi, and Hinglish forwards.
  • Detect emotional urgency manipulation, fake domain patterns, and financial phishing triggers.
  • Compare claims with curated, source-backed examples; mark unmatched claims as UNVERIFIED instead of guessing.
  • Generate comprehensive, academic-grade reality matrix dossiers instead of naive percentage scores.

Datasets Used

Template-generated seed set 360 synthetic SCAM / HOAX / LEGIT messages in English, Hindi and Hinglish; evaluated with template-grouped cross-validation.
Curated fact registry 5 source-backed cases (PIB, RBI, ISRO, news reports) used for similarity retrieval.
Future work: LIAR / FakeNewsNet Public datasets planned for transformer fine-tuning; not used by the current model.

Professor Viva Q&A Defense Guide

Q1: How does the system handle Hinglish (mixed Hindi + English) text forwards?

Word n-grams plus character n-grams (2–5) in TF-IDF capture spelling variants of romanised Hindi (e.g. band/bandh, jaldi/jldi) without a Hindi tokenizer, and the same character features cover Devanagari. A multilingual transformer (XLM-R / MuRIL) would handle code-mixing better and is future work.

Q2: Why use Transformer architectures over traditional SVM or Random Forest models?

The deployed model is TF-IDF + Logistic Regression: fast (about 1 ms), gives class probabilities, and was compared with Linear SVM and Naive Bayes in the Benchmarks tab (measured, not quoted). Transformers capture context better but need a GPU and far more labelled data (e.g. LIAR); they were not trained here.

Q3: How does the system prevent AI hallucination during fact-checking?

The ML score never decides REAL or FAKE. Those verdicts come only from source-backed evidence: the curated registry or a published Google Fact Check review. Without evidence the result is UNVERIFIED. The classifier only flags scam/hoax-style language, and scam detection relies on URL, urgency and credential-request patterns. Limitation: the training set is small and synthetic, so accuracy figures are indicative only.
